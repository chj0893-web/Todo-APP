# ✅ My Tasks — 브라우저 할 일 관리 앱

서버 없이 브라우저만으로 동작하는 할 일(Todo) 관리 앱입니다. 순수 HTML / CSS / JavaScript로 만들어졌고, 데이터는 브라우저의 LocalStorage에 저장되어 새로고침하거나 브라우저를 닫아도 유지됩니다.

## 빠른 시작

1. 이 폴더의 `index.html`을 더블클릭해 브라우저(Chrome, Edge 등)로 엽니다.
2. 입력창에 할 일을 적고 **Enter** 또는 **추가** 버튼을 누릅니다.
3. 끝!

설치, 빌드, 인터넷 연결 모두 필요 없습니다.

## 주요 기능

| 기능 | 사용 방법 |
| --- | --- |
| 할 일 추가 | 입력창에 내용 입력 → Enter 또는 **추가** |
| 카테고리 | 업무 · 개인 · 공부 중 선택. 입력 내용에 "회의", "공부", "운동" 같은 단어가 있으면 자동으로 추천됩니다 |
| 완료 처리 | 항목 왼쪽 체크박스 클릭 (취소선 표시) |
| 수정 | 할 일 텍스트를 **더블클릭** → 내용·카테고리 수정 → Enter 저장, Esc 취소 |
| 삭제 | 항목 오른쪽 **×** 버튼 |
| 완료 항목 일괄 삭제 | 사이드바 **완료된 항목 모두 삭제** (확인 창이 뜹니다) |
| 필터 | 사이드바의 전체 / 업무 / 개인 / 공부 버튼 |
| 검색 | 상단 검색창에 입력하면 즉시 필터링 |
| 정렬 | 최신순 · 오래된순 · 카테고리순 · 완료 상태순 · 수동 정렬 (선택한 정렬은 기억됩니다) |
| 순서 직접 변경 | 항목을 마우스로 드래그해서 원하는 위치에 놓기 (자동으로 수동 정렬로 바뀝니다) |
| 다크 모드 | 우측 상단 스위치. 선택한 테마는 기억됩니다 |
| 대시보드 | 전체 진행률, 카테고리별 진행률, 오늘 추가한 개수 |
| 백업 / 복원 | **내보내기 (JSON)** 로 파일 저장, **가져오기** 로 파일 불러오기 |

## 키보드 단축키

| 단축키 | 동작 |
| --- | --- |
| `Alt + N` | 새 할 일 입력창으로 이동 |
| `Alt + 1` | 전체 보기 |
| `Alt + 2` | 업무만 보기 |
| `Alt + 3` | 개인만 보기 |
| `Alt + 4` | 공부만 보기 |
| `Enter` / `Esc` (수정 중) | 저장 / 취소 |

## 데이터 백업과 복원

- **내보내기**를 누르면 `my-tasks-backup-YYYYMMDD.json` 파일이 다운로드 폴더에 저장됩니다.
- **가져오기**를 누르고 JSON 파일을 선택하면 현재 목록을 그 파일의 내용으로 교체합니다. 기존 데이터가 있으면 먼저 백업할지 물어봅니다.
- 데이터는 브라우저별로 따로 저장됩니다. 다른 브라우저나 PC로 옮기려면 내보내기 → 가져오기를 이용하세요.
- 브라우저의 "사이트 데이터 삭제"를 실행하면 목록이 사라지니 중요한 내용은 내보내기로 백업해 두세요.

## 파일 구성

```text
index.html   화면 구조
style.css    디자인 (라이트/다크 테마, 반응형)
script.js    동작 로직
README.md    이 문서
archive/     이전 버전 보관 (실행에는 필요 없음)
```

## 배포하기 (선택)

1. GitHub에 새 저장소를 만들고 `index.html`, `style.css`, `script.js`, `README.md`를 업로드합니다.
2. [Vercel](https://vercel.com)에 GitHub로 로그인 → **Add New → Project** → 저장소 Import → **Deploy**.
3. 발급된 `https://<프로젝트명>.vercel.app` 주소로 어디서든 접속할 수 있습니다.

## 자주 묻는 질문

- **모바일에서도 되나요?** 네. 화면 폭에 맞춰 한 줄 레이아웃으로 바뀝니다. 단, 드래그로 순서 바꾸기는 마우스 환경에서만 동작합니다.
- **데이터가 사라졌어요.** 시크릿 창이나 다른 브라우저 프로필에서는 별도 저장소를 사용합니다. 원래 사용하던 브라우저에서 열어 보세요.
- **한도가 있나요?** 할 일 한 건당 200자까지 입력할 수 있고, 항목 수는 수백 개까지도 원활하게 동작합니다.
